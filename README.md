# Clicky

A tiny macOS menu bar companion: press ⌃⌥Space, circle anything on screen, and Claude explains it in a little bubble next to your cursor.

It runs on your own logged-in Claude Code CLI, so there's no extra account or API key. Requires macOS 26+, Xcode 26+ and Claude Code. Open `Clicky.xcodeproj` and press ⌘R.
